# Titanic Survival Prediction  (Logistic Regression)

This project uses the **Titanic dataset** to build a Machine Learning model that predicts whether a passenger survived the Titanic disaster. The notebook includes **EDA**, **data preprocessing**, **feature engineering**, and a **Logistic Regression** classifier.

---

##  Project Overview

The objective of this notebook is to predict **Survived (0/1)** using passenger information such as:

- Passenger class (`Pclass`)
- Gender (`Sex`)
- Age
- Fare
- Embarkation port (`Embarked`)
- Title extracted from name (Mr, Mrs, Miss, etc.)

---

##  Dataset

The notebook uses:

- `Titanic-Dataset.csv`

 Make sure the dataset is in the same folder as the notebook before running.
